## R1 室内壳（2026-11-25 交付）

### 改了什么

| 项 | 内容 |
|---|---|
| 新文件 `frontend/src/three/envInterior.ts` | 室内壳全部几何：四面外墙（8m 高 × 0.25m 厚）、0.8m 踢脚线、墙角 0.4×0.4 包柱、南墙 6×4.5 卷帘门洞（导轨+卷筒，洞空着）、东西墙各 3 个 2×1.5 高窗洞（y 4.5~6，0.12 窗框 + 玻璃）、桁架每 6m 一榀（0.12 方管弦杆+腹杆+3 道檩条）、灯带 5 道沿用 emissive 组。旧的柱子/桁架/灯带三个 builder 已删除，避免结构重影 |
| 顶点色并入既有 6 组 | 全部部件按顶点色进 matte / metal / paint / emissive / glass，**不新增材质、不新增 draw call**（`envDrawables` 仍 ≤6） |
| 相机适配 | `ORBIT_LIMITS.maxDistance` 90→72；overview `[0,40,48]`→`[0,36,46]`；入场起点/路径同步收敛（距原点 65.8 < 72，否则第一帧被夹回会"瞬移"） |
| 室内补光 | HemisphereLight(#9fb2c4, #1f2b3a) + 两盏不投阴影的 DirectionalLight（#dce8f4 / #cfdcea）当"天窗光" |
| **室外剖切（超出作者清单，见偏差 D-66）** | 相机落在某车间某侧室外时，那一侧的墙整组退化为不可见。实现：`EnvPart.cut` 标记 → 合并索引三组写 0（退化三角形）→ 相机回到室内或该侧时写回原值。阴影 pass 共用同一份索引，不会"墙没了影子还在"。包柱/桁架不剖 |
| LINE-A1 预设（超出作者清单，见偏差 D-64） | `[-20,7,14]`→`[-15,3,-1]`：旧机位贴着灯带高度，画面顶部露一条无屋面板的天空，视线尽头不是墙 |

