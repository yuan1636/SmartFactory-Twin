## 本批踩到并修掉的四个坑（详见附录 B D-67 ~ D-70）

1. **非索引几何合并不了**：`RoundedBoxGeometry` 没有 `index`，而 `Box/Cylinder/Plane` 有，
   `mergeGeometries` 直接返回 null。改为全体统一 `toNonIndexed()`；顺带把圆角细分 2→1
   （每个圆角箱 300 → 108 三角，这个尺寸下看不出差别，符合性能优先）。
2. **`vite --force` 不是解法**：它要删 `.vite/deps` 的 93 个文件，触发沙箱批量删除保护，
   dev server 启动直接失败。改为把整个 `.vite` 目录**改名**让 Vite 重建，不删任何文件。
3. **并发写入让 Vite 缓存了半截模块**：页面报 `builders.ts does not provide an export named
   'applyDeviceState'`，但磁盘上导出齐全。`touch` 该文件触发一次重转换即恢复。
4. **假接触阴影被室内补光照亮**：`MeshStandardMaterial` 受光后，贴地暗晕呈现为一块浅灰
   「设备基础台」而不是纯黑阴影。把尺寸从 4.6×3.1 收到 4.2×2.75、中心色提亮后，
   不再出现孤立的硬边黑块；当前观感如实记为「基础台」，**没有把它称作柔和接触阴影**。
   若要做真·柔和阴影需独立透明材质，会每台 +1 draw call 并让 CONVEYOR 超「≤3 mesh」，本批不做。
